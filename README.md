## Frameworks and Libraries

- [Baileys](https://github.com/WhiskeySockets/Baileys) - Socket-based TypeScript/JavaScript API for WhatsApp Web. The most widely used library for building WhatsApp bots without the Business API. No browser required.
- [whatsapp-web.js](https://github.com/wwebjs/whatsapp-web.js) - A WhatsApp client library for Node.js that connects through the WhatsApp Web browser app. Feature-rich with active community maintenance.
- [WAHA](https://github.com/devlikeapro/waha) - WhatsApp HTTP API (REST API) that you can configure in a click. Supports three engines: WEBJS (browser-based), NOWEB (WebSocket Node.js), and GOWS (WebSocket Go).
- [Venom](https://github.com/vynect/venom) - High-performance JavaScript system for creating WhatsApp bots with support for AI-based sentence recognition, customer service flows, and all types of interaction design.
- [WPPConnect](https://github.com/wppconnect-team/wppconnect) - Open-source project developed by the JavaScript community. Exports WhatsApp Web functions to Node.js for building customer service, media sending, and AI-powered interactions.
- [GOWA](https://github.com/aldinokemal/go-whatsapp-web-multidevice) - WhatsApp REST API written in Go with support for UI, multi-account, webhooks, MCP, and Chatwoot integration. Memory-efficient.
- [wa-automate-nodejs](https://github.com/open-wa/wa-automate-nodejs) - The most reliable tool for WhatsApp chatbots with advanced features including multi-device support, anti-ban mechanisms, and extensive event handling.
- [Wechaty](https://github.com/wechaty/wechaty) - Conversational RPA SDK for chatbot makers supporting multiple messaging platforms including WhatsApp. Write once, run on any IM platform.
- [Evolution API](https://github.com/evolutionapi/evolution-api) - Open-source WhatsApp integration API with support for multi-instance management, webhooks, and integration with n8n, Chatwoot, and RabbitMQ.
- [OpenWA](https://github.com/rmyndharis/OpenWA) - Free, open-source, self-hosted WhatsApp API gateway for building business bots at scale.

## AI-Powered Bots

- [whatsapp-chatgpt](https://github.com/askrella/whatsapp-chatgpt) - ChatGPT + DALL-E + WhatsApp = AI assistant. Supports voice messages, image generation, and conversational context via OpenAI APIs.
- [whatsapp-ai-bot](https://github.com/Zain-ul-din/whatsapp-ai-bot) - WhatsApp AI bot using multiple AI models including DeepSeek, GPT-4, DALL-E, Gemini, and StabilityAI for text, image, and multimodal responses.
- [Whatsapp-Langgraph-Agent-Integration](https://github.com/lucasboscatti/Whatsapp-Langgraph-Agent-Integration) - WhatsApp AI agent powered by LangGraph, FastAPI, and Groq. Acts as an empathetic therapist handling text and voice messages with PostgreSQL-backed memory and multi-language support.
- [agentic-whatsapp-ai](https://github.com/FareedKhan-dev/agentic-whatsapp-ai) - Advanced agentic eCommerce WhatsApp bot demonstrating multi-step reasoning and tool use for product discovery, order management, and customer support.
- [whatsapp-ai-clone](https://github.com/kinggongzilla/whatsapp-ai-clone) - Create a personalized AI chatbot trained on your own WhatsApp chat export. Fine-tunes a language model to mimic your writing style.
- [Whatsapp-Ai-BOT](https://github.com/yesbhautik/Whatsapp-Ai-BOT) - AI chatbot for WhatsApp powered by OpenAI ChatGPT, Playground, and DALL-E. Built in Node.js with session handling and rate-limit protection.
- [WhatsBot](https://github.com/yaasiin-ayeva/WhatsBot) - WhatsApp AI bot with unofficial API support. Handles voice messages, video downloads from social networks, campaigns, and automation workflows.
- [whatsapp_ai_bot](https://github.com/pycodebr/whatsapp_ai_bot) - AI chatbot for WhatsApp using LangChain and Evolution API. Demonstrates RAG patterns and tool-use within the WhatsApp channel.
- [whatsapp_ai_chatbot](https://github.com/pycodebr/whatsapp_ai_chatbot) - AI chatbot for WhatsApp using LangChain and WAHA. Clean integration pattern for LLM-powered conversations over the REST API.
- [whatsapp-ai-filter](https://github.com/avikalpg/whatsapp-ai-filter) - AI-powered filter for WhatsApp that surfaces important messages and suppresses noise. Uses LLMs to rank and summarize conversations.
- [laravel-whatsapp-ai-agent](https://github.com/jigar-dhulla/laravel-whatsapp-ai-agent) - Laravel package for building WhatsApp AI agents. Provides clean abstractions for intent detection, entity extraction, and multi-turn conversation state.
- [WhatsAppInfoBot](https://github.com/adiwajshing/WhatsAppInfoBot) - Lightweight framework for building WhatsApp information bots. Focuses on structured command parsing and response generation.

## Business API Wrappers

- [whatsapp-api-js](https://github.com/Secreto31126/whatsapp-api-js) - Lightweight, dependency-free TypeScript library for interacting with the official WhatsApp Cloud API. Supports all message types, webhooks, and template management.
- [Evolution API](https://github.com/evolutionapi/evolution-api) - Full-featured open-source wrapper for the WhatsApp Business API with multi-instance support, REST endpoints, and native integrations with popular tools.

## Chatbot Builders

- [Botpress](https://github.com/botpress/botpress) - Open-source hub for building and deploying GPT/LLM agents with native WhatsApp channel support. Visual flow builder with code-first fallback.
- [Rasa](https://github.com/RasaHQ/rasa) - Open-source machine learning framework for automated text and voice conversations. Supports WhatsApp via connector integrations. NLU, dialogue management, and custom actions.
- [Dify](https://github.com/langgenius/dify) - Agentic workflow and RAG pipeline platform with rich AI model and tool support. Can be integrated with WhatsApp via webhook connectors.
- [Chatwoot](https://github.com/chatwoot/chatwoot) - Open-source live-chat, email support, and omni-channel desk with native WhatsApp Business API integration and AI-assist features.
- [BotMan](https://github.com/botman/botman) - Framework-agnostic PHP library for building chatbots across multiple messaging platforms including WhatsApp.
