# Contributing

PRs welcome! Please ensure:

- The project is actively maintained (last commit within 12 months)
- Include a brief, accurate description (one sentence)
- Place it in the correct category alphabetically
- The GitHub repository is public and not archived
- No duplicate entries — search the list before adding
- Link directly to the GitHub repository, not a homepage or npm page

## Pull Request Process

1. Fork the repository
2. Add your entry in the correct category, maintaining alphabetical order
3. Use the format: `- [Name](link) - Description.`
4. Open a pull request with a short title explaining what you are adding

## What NOT to Add

- Closed-source or commercial-only tools (no free self-hosted tier)
- Abandoned projects (no activity in the past 12 months)
- Projects that only mention WhatsApp in passing — the integration must be a core feature
- Spam bots or tools designed for unsolicited messaging

## Code of Conduct

Be respectful and constructive in all interactions. This project follows the [Contributor Covenant](https://www.contributor-covenant.org/).
